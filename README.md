Banking Fraud Analytics Dashboard & Fraud Detection Model
Project Overview

This project focuses on identifying potentially fraudulent banking transactions using Machine Learning and Business Intelligence techniques. The solution combines data preprocessing, fraud prediction, and interactive data visualization to help financial institutions monitor transaction risk and support fraud prevention strategies.

The project includes a Logistic Regression-based fraud detection model and a Power BI dashboard that provides real-time insights into fraud rates, transaction patterns, financial exposure, and risk distribution.

Objectives
Analyze banking transaction data to identify suspicious activities.
Build a machine learning model to classify transactions as Fraud or Genuine.
Visualize fraud trends and risk indicators through interactive dashboards.
Support data-driven decision-making for fraud monitoring and risk management.
